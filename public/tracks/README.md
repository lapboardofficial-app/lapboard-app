Track images load automatically from this folder.

Use either the track id or the track name slug as the folder name:

- `public/tracks/k1-circuit-winchester/`
- `public/tracks/k1-circuit/`

Inside that folder, add one of these common image files:

- `cover.jpg`, `cover.png`, `cover.webp`, or `cover.jpeg` for the track card image
- `track.jpg`, `track.png`, `track.webp`, or `track.jpeg` as another fallback
- layout-specific files like `north-track.jpg`, `pro-track.jpg`, or `pro-track-with-chicanes.jpg`

Examples:

- `public/tracks/k1-circuit-winchester/cover.jpg`
- `public/tracks/k1-circuit-winchester/north-track.png`
- `public/tracks/k1-speed-torrance/cover.webp`
